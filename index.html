운동회 소음, 미분과 적분으로 잡아내기

갑자기 커지는 소리(미분)와 오래 이어지는 큰 소리(적분)를 따로 감지하고, 이미 시끄러운 상태에서 다시 소리가 폭발하면 🔴 복합 위험 사이렌을 울립니다.

🎙 소리 파일 ➜ 📏 0.1초마다 소리 크기 L(t) ➜ 🟡 미분: 얼마나 빨리 커지나 🔵 적분: 얼마나 쌓였나 ➜ 🚦 경보 판단 A·B·C·D ➜ 🔔 단계별 경보음
① 왜 필요할까?
  • 운동회 소음은 두 종류: 갑자기 "와!" 하고 커지는 소리와 오래 이어지는 함성
  • 귀로만 판단하면 사람마다 기준이 다름
  • ➜ 숫자 기준으로 자동 경보
② 미분 ➜ 🟡 A 돌발 급증
  • 0.5초 동안 소리가 얼마나 빨리 커지나 (평균변화율 ≈ 미분계수)
  • 기준: 초당 30 dB 이상, 1.0초 유지
  • 문 쾅 같은 순간 소리는 무시
③ 적분 ➜ 🔵 C 누적 피로
  • 최근 30초 그래프 아래 넓이 ÷ 30초 = 평균 소리 크기
  • 기준: 평균 58 dB 이상
  • 🟠 B 지속 고소음: 배경보다 +20 dB가 30초 넘게 지속
④ 둘이 만나면 ➜ 🔴 D 복합 위험
  • 이미 소리가 쌓인 상태(C)에서 다시 급증(A)

대기 시간

미분 — 갑자기 커지는 소리 (🟡 A 경보)

빨간 점선을 넘고, 커진 상태가 유지되면 경보
L′(t) = dL(t)/dt = limΔt→0 {L(t) − L(t−Δt)} / Δt ≒ {L(t) − L(t−0.5)} / 0.5
L′(t) = dL(t)/dt = limΔt→0 {L(t) − L(t−Δt)} / Δt ≒ {L(t) − L(t−0.5)} / 0.5

소리 데이터는 0.1초 간격으로만 있어서 Δt를 0까지 줄일 수 없으므로, Δt = 0.5초의 평균변화율로 순간변화율(미분계수)을 근사합니다.

그래프 1. 소리 크기 L(t)

주황 배경 = 큰 소리가 30초 넘게 이어진 구간

그래프 2. 소리가 커지는 속도 L′(t)

0.5초 평균변화율 · 빨간 점선을 넘으면 급증 후보

적분 — 오래 쌓인 소리 (🔵 C 경보)

기준: 평균 ≥ 58 dB ⇔ 넓이 ≥ 1,740 dB·초
L̄(t) = (1/30) ∫t−30t L(s) ds

그래프 1 아래에서 최근 30초 동안의 넓이를 구하고, 구간 길이 30초로 나눈 값(구간 평균)입니다.
